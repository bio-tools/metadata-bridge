Bidirectional bridge: GitHub ⇄ bio.tools
==========================================

Extract bio.tools metadata from GitHub repositories, and propose improvements to GitHub repositories
from their bio.tools entries as pull requests and issues.
Use it from the command line, as a REST API, or as a Python package.

*This project started at the ELIXIR BioHackathon Europe 2025* (`original repository <https://github.com/bio-tools/biohackathon2025>`_).
